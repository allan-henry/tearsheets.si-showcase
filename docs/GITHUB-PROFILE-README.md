## How I approach AI-native product work

- Start with the customer's actual workflow and the cost of getting it wrong.
- Separate what an automated system discovered from what the available evidence establishes.
- Build explicit acceptance tests, negative controls, and correction paths—not just a successful demonstration.
- Use AI coding agents with bounded responsibilities, shared product principles, versioned specifications, and independent reviews.
- Keep authentication, data ownership, privacy, operating budgets, and release approvals part of the design.

These public repositories are purpose-built demonstrations using fictional inputs. The complete working systems, private source repositories, customer information, and operational materials are not published here.
